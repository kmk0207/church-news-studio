# 기존 자료 분석과 템플릿 결정

분석일: 2026-11-16. 파일명은 로컬 자료에서만 열거하며 원본이나 인물 사진을 코드 저장소에 복사하지 않는다.

## 실제 파일 검사

- `data/archive/week01/`: PNG 5개
- `data/archive/week02/`: PNG 10개
- `data/archive/week03/`: 비어 있음
- 총 15개 모두 1920×1080, 16:9, RGBA 이미지이며 손상된 이미지는 없다.
- SHA-256 기준 고유 이미지 9개. 중복 그룹은 5개이며 중복 사본이 6개이다.
- week02의 각 파일과 `(1)` 사본이 동일하다. 새가족 안내 이미지 하나는 week01과 week02에 걸쳐 세 번 나타난다.
- `data/assets/logos`, `backgrounds`, `fonts`, `data/samples/photos`는 비어 있다. IDE에 열린 글꼴 탭과 별개로 실제 폴더에서 읽을 수 있는 글꼴 파일은 없었다.
- `data/samples/announcements.txt`는 0바이트이다. 별도 `data/assit` 폴더는 보존했다.
- week01/02 폴더명은 시간 순서를 보장하지 않는다. 파일명 날짜가 week01에서 더 최근이므로 향후 '지난주' 선택은 단순 폴더명 정렬로 구현하면 안 된다.

재현 명령은 `python -m church_studio analyze`이다. 파일별 해상도·크기·해시·대표 색상은 `outputs/analysis/archive-report.json`, 고유 이미지 모음은 `outputs/analysis/contact-sheet.jpg`에 생성한다. 픽셀 색상 집계는 자동이며 다음 의미 분류는 실제 이미지 육안 확인 결과이다. OCR이나 외부 AI는 사용하지 않았다.

## 디자인과 문체

고유 9개 중 파란 표지형 2개, 큰 텍스트 공지 4개, 큰 사진 공지 2개, 작은 인라인 이미지가 포함된 혼합 공지 1개로 분류했다.

메모형 광고는 흰 바탕과 회색 창 프레임, 좌상단 공지 번호·제목, 넓은 여백, 검정 중앙 본문으로 구성된다. 노란색 형광펜 스타일과 분홍색 핵심 문구를 사용한다. 사진은 안내 문구 아래에 한 장, 또는 두 장 나란히 놓이는 경우가 있다. 표지는 흰 바탕, 중앙/왼쪽 대표 사진, 오른쪽 파란 안내 패널이 특징이다.

문체는 짧은 안내 제목과 정중한 참여 요청이며 일정·시간·장소를 별도 줄로 제시한다. 이를 참고하여 수동 템플릿을 만들었으며, 기존 문장·날짜·인명·장소를 새 광고에 넣지 않았다.

## 재사용 가능한 구조

`notice`: 메모형 공통 프레임, 제목 강조, 여러 문단과 사실 정보 목록. 주간 모임·일정·안내용이다.

`photo`: 같은 프레임에 사진 1~3개, 캡션, 문단, 사실 정보를 넣는다. 기존 사진형 1장/2장 구성을 지원한다.

`cover`: 대표 사진, 왼쪽 큰 제목, 파란 오른쪽 안내 패널을 지원한다. 표지의 사진·안내 분리를 참고했다.

기본 캔버스는 원본 해상도인 1920×1080으로 확정했다. 2배 출력은 벡터 텍스트를 3840×2160으로 렌더링하지만 저해상도 원본 사진의 세부 정보까지 복원하지는 않는다.

## 원본과의 차이 및 자료 요청

- 원본은 이미 합성된 래스터 이미지이다. 정확한 글꼴·벡터 도형·레이어·텍스트 상자를 복구하지 않았다.
- 현재 메모 프레임은 직접 작성한 CSS이며 원본 앱의 툴바 아이콘은 단순화했다. 카드 크기·여백·줄 간격은 편집과 넘침 검증에 맞게 조정했다.
- 표지의 손글씨 로고, 폴더 아이콘, 외부 캐릭터와 장식은 복제하지 않았다. 작은 이미지가 문장 옆에 붙는 혼합형은 현재 별도 템플릿이 없고 일반 사진형으로 대체한다.
- 맑은 고딕을 로컬 검증용으로 사용해 원본 글꼴과 자폭·굵기가 다를 수 있다. 원본 서체는 이미지로 확정할 수 없다.
- 실제 교회 사진·로고는 추출하거나 새 광고에 재사용하지 않았다. 데모는 가상 정보와 직접 그린 테스트 이미지이다.
- 정확한 재현을 위해 사용 권한이 확인된 로고 원본(PNG/SVG), 원본 한글 폰트(TTF/OTF 및 라이선스), 배경·장식 원본, 사진 파일, 대표 광고의 텍스트가 필요하다.
- 관리자에게 3종의 틀과 강조색·여백을 먼저 검토받고, 실제 한 주 내용과 고해상도 사진을 받아 운영 전 비교해야 한다.
