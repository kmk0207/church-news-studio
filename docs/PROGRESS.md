### 차이점과 남은 한계

원본 픽셀이나 레이어를 복원한 것이 아니라 레이아웃을 참고한 새 수동 템플릿이다. 맑은 고딕 사용, 툴바 단순화, 카드 여백 조정 때문에 글꼴·장식·배치가 원본과 완전히 같지 않다. 표지의 손글씨와 폴더 장식, 작은 인라인 이미지 전용 배치는 구현하지 않았다. 실제 로고·사진·일정은 샘플에 사용하지 않았다.

사용자 지정 글꼴의 모든 문자 지원, 날짜·요일 일치, 과거 정보 혼입 여부를 의미적으로 검증하는 기능은 아직 없다. 한글과 특수문자, 최종 사실 정보는 관리자가 확인해야 한다. PNG만 지원하며 JPG/ZIP/PPTX는 미구현이다. GUI 편집·SQLite 이력·AI·RAG·배포는 다음 단계 범위이며 완료로 표시하지 않는다. Linux/macOS 실행은 검증하지 않았다.

### 아직 완료하지 않은 항목과 다음 작업

Phase 2 전체 완료로 표시하지 않는다. 사용자 제공 중앙 사진과 실제 곡명이 필요하다. 이를 받아 새 표지의 실제 송출본과 사진 크롭을 확인한 뒤, 외부 전송 대상과 사용 모델에 대한 동의를 받아 Gemini 실연결·스키마 호환·분류/누락 품질·토큰 비용을 검증한다. 사용자가 원하는 경우 로컬 Sentence Transformers 모델을 준비해 한국어 검색 품질을 검증한다.

현재는 원문 부분 문자열 검사와 사람의 최종 검토를 사용한다. 날짜·요일 일치와 사실 진위, 모든 광고의 빠짐없는 분리, 사진 내용 기반 자동 연결, 검색 결과를 활용한 실응답 품질은 아직 보장하지 않는다. 승인된 기존 이미지의 실제 AI 스타일 프로필·Few-shot/RAG 통합 품질 검증도 남아 있다. 전체 UI·서버 배포는 진행하지 않았다.

## Phase 3 — 사용자 UI 및 번호별 제작 흐름

기준일: 2026-11-16. 앞의 Phase 2 기록은 당시 상태이며 현재는 Streamlit UI를 구현했다. 기존 Phase 3 전체 검사 결과는 뒤늦게 회수하여 **38 passed in 97.58s**임을 확인했다. 직접 브라우저 점검은 컴퓨터 사용 도구가 Windows URL을 신뢰할 수 있게 판별하지 못해 중단되었고 재시도하지 않았다.

사용자의 후속 요청으로 기본 제작 방식을 다음과 같이 바꿨다.

- 새 주간 작업에는 고정 예배 표지 한 장을 자동 포함한다. 표지 종류 선택·추가 버튼을 제거하고 첫 장 위치를 유지한다.
- 교회·장소·환영·브랜드·슬로건은 최초 기본 설정에서 관리한다. 주간 화면의 제목·항목명은 읽기 전용이다. 날짜·시간·Song List·담당자/성경 본문·사진은 입력할 수 있다.
- `0.`, `1.` 등의 번호를 파싱해 0번을 포함한 각 번호를 정확히 한 페이지로 만든다. 번호 안의 여러 줄·빈 줄은 페이지를 나누지 않는다.
- 사진은 사용자가 번호별로 지정한다. 사진 유무로 텍스트/사진 템플릿을 결정하며 AI가 배정을 바꾸지 않는다.
- 로컬 기본 문체 규칙과 별도 Gemini `copy` 작업을 추가했다. 기존 발췌형 `structure`의 엄격한 원문 문구 검사와 구분해 자연스러운 제목·본문 작성을 허용한다.
- Gemini 지침에 교회 광고 말투와 Few-shot 예시를 넣었다. 모델 자체의 학습·fine-tuning은 하지 않는다. 이번 작업 중 실제 API 호출은 0회다.
- 번호·페이지 수·숫자·명시적 사실값·우천 취소 조건을 검사한다. 인명과 모든 의미의 진위를 증명하는 검사는 아니며 최종 검토는 필요하다.
- 값이 없는 복장·모임시간은 추정하지 않고 확인 요청으로 남긴다. 원문과 검토 요청을 광고 편집 화면에 표시한다.
- 번호 목록 재작성 시 같은 번호의 카드 ID를 유지하고 목록을 교체한다. 표지와 별도 수동 광고는 보존하고 이전 저장본은 SQLite project_revisions에 보관한다. 버전 복원 UI는 아직 없다.
- 고정 표지 설정이 바뀌면 기존 이미지가 최신으로 취급되지 않도록 무효화한다.
