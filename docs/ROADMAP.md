# 개발 계획

## Phase 1 — 로컬 템플릿과 이미지 생성 (완료)

상태: 구현 및 실제 PNG 검증 완료. pytest 13개 통과. 상세 결과는 PROGRESS.md에 기록했다.

1. 실제 파일 목록, 이미지 크기·비율·중복·레이아웃 확인
2. 검증 가능한 Pydantic 입력 구조와 템플릿 정의
3. Jinja2 HTML/CSS, Pillow 사진 처리, Playwright PNG 렌더링
4. 가상 한국어 광고와 사진을 이용한 실제 결과물 생성
5. 한글·텍스트 넘침·사진 비율·원본 보존 테스트와 문서화

완료 기준: 외부 AI 없이 기존 광고의 구성을 참고한 새 텍스트·사진 광고를 실제 PNG로 생성한다. 완료 후 사용자 승인 전까지 중단한다.

## Phase 2 — 사용자 승인으로 진행 중

2026-11-16 사용자가 착수를 승인했다. 우선 예배 표지를 중앙 사진·오른쪽 Song List·날짜·환영·예배 순서로 개선했다. 확인된 담당자·성경봉독·예시 날짜는 로컬 입력에 반영했다. 사진과 실제 곡명은 제공 대기이다.

구현 및 로컬 검증: 예배 표지, 원문 근거 검사, Gemini 전송 계획/동의 경계, SDK 모의 응답, 스타일 프로필 저장·중복 제거, SQLite·NumPy 검색, AI 결과의 렌더링 JSON 변환.

남은 운영 검증: 실제 Gemini API 연결과 응답 품질·토큰 비용, 승인된 원본의 멀티모달 분석, 실제 사진 연결, Sentence Transformers 로컬 모델 실행과 검색 품질. Phase 2 착수는 실제 교회 자료의 외부 전송 동의와 별개이며 현재 외부 API 호출은 0회이다.

- Google Gen AI SDK/Gemini를 별도 서비스 계층에 연결
- 승인받은 이미지로 디자인·문체 분석 후 스타일 프로필 검토·저장
- 자연어 → Pydantic 광고 구조, 누락 정보 확인, 원문 근거 연결
- SQLite 메타데이터와 Sentence Transformers/NumPy 유사도 검색
- 디자인만 참고하고 과거 사실 정보는 신규 광고에 복사하지 않는 추천
- 비용·전송 대상 기록과 명시적 외부 전송 승인

## Phase 3 — 사용자 제작·편집 흐름

Streamlit 주간 저장·사진 보관함·편집·생성·PNG/JPG/ZIP·지난주 복사·기록을 구현했다. 사용자 요청으로 기본 흐름을 고정 cover + 번호별 광고 각 1장으로 변경했다. 사진은 번호별 수동 연결, 문체는 기본 규칙 또는 동의받은 Gemini copy 작업으로 작성한다. 자세한 사용법은 PHASE3.md에 기록한다. 실 API와 직접 브라우저 시각 검증은 남아 있다.

## Phase 4 — 운영 검증

실제 한 주 광고를 수작업 결과와 비교하고 내용 누락·과거 정보 혼입·한글·넘침·사진 비율을 검증한다. 생성 시간과 API 비용을 측정하고 로컬 설치 및 저비용 운영 안내를 작성한다. PPTX는 필요성 확인 후 선택 구현한다.
